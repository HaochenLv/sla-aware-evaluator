## Interpretation
E29 clarifies why the coarse full-debt rule is not merely an implementation accident. Under the intentionally reduced Evaluator state, hidden stage/execution phase changes actual interference while the visible macro-state is the same. If the Evaluator refuses to model stage scheduling/phase, a conservative state-only rule must take a worst-case envelope over those hidden phases. The observed envelope already reaches `95.3143%` of the independently profiled full blocking-service debt, so there is little evidence-backed room for a global tightening. This is not a proof that multiplier 1 is universally minimal, and `0.953143` must **not** be fitted as a coefficient; unseen phases/workloads can be worse. A materially tighter rule would require extra observable phase/state or a different analytically justified bound.
